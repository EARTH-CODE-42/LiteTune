# LiteTune 1.3

## 新增功能 ✨

- **右键菜单**：播客列表右键可刷新 / 删除订阅 / 删除该播客缓存；缓存视图右键可清空全部缓存 / 打开缓存文件夹；剧集右键可下载 / 删除该集缓存（右键同时选中该行）
- **缓存视图按播客排序**：已缓存剧集列表新增「播客」列，点击表头即可按播客名排序
- **播客搜索**：在「添加订阅」框输入关键词，回车即从 iTunes 搜索，结果列表单击填回 / 双击直接添加

## 改进与修复 🛠

- **订阅源兼容性**：自动读取系统代理设置（如 Clash），FeedBurner、BBC、Buzzsprout 等源均可正常解析；接受所有 2xx 响应码
- **深色主题统一**：设置菜单、右键菜单、悬停提示（按钮 / 剧集 / 播客封面）全部统一为深色配色
- **播客悬停封面放大**：播客列表悬停提示中的封面图放大显示，信息更清晰
- **缓存视图排序箭头修正**：点击不同表头时排序指示箭头显示在正确的列上
- **剧集悬停提示**：深色模式下背景与文字配色正确，不再出现黑底黑字

## What's New in 1.3

### Features ✨

- **Context menus**: right-click a podcast to refresh / delete / clear its cache; right-click the Cached row to clear all cache or open the folder; right-click an episode to download or delete its cache (right-click also selects the row)
- **Sort cached episodes by podcast**: the cached list now has a Podcast column — click the header to sort by podcast name
- **Podcast search**: type a keyword in the Add Subscription box and press Enter to search iTunes; single-click fills the URL back, double-click adds immediately

### Improvements & Fixes 🛠

- **Feed compatibility**: auto-reads the system proxy (e.g. Clash); FeedBurner, BBC, Buzzsprout and similar feeds now parse correctly; all 2xx response codes accepted
- **Dark theme consistency**: settings menu, context menus and all tooltips (buttons / episodes / podcast cover) now share the same dark palette
- **Enlarged podcast cover in tooltip**: the cover art in the podcast hover tooltip is now larger for better readability
- **Cached-view sort arrow fix**: the sort indicator arrow now appears on the correct column when clicking different headers
- **Episode tooltip**: correct background and text colors in dark mode — no more black text on black background
